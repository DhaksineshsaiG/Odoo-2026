# TransitOps

Smart Transport Operations Platform.

This repository is currently in Phase 0: project skeleton, application shell, routing, API foundation, and development tooling only.

## Structure

- `frontend` - React, Vite, TypeScript, Tailwind CSS, React Router
- `backend` - Node.js, Express, TypeScript, MongoDB/Mongoose, JWT-ready structure

## Quick Start

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - run frontend and backend in development mode
- `npm run build` - build both apps
- `npm run lint` - lint both apps
- `npm run format` - format the repository with Prettier

Copy each `.env.example` file to `.env` inside its folder before running services that require environment variables.
